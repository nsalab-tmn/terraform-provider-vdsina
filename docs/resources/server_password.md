# vdsina_server_password (Resource)

Changes the root password on a VDSina server.

## Example Usage

### Change Root Password

```hcl
resource "vdsina_server_password" "reset" {
  server_id = vdsina_server.web.id
}

output "new_password" {
  value     = vdsina_server_password.reset.password
  sensitive = true
}
```

### Password Reset with Trigger

```hcl
resource "vdsina_server_password" "periodic" {
  server_id = vdsina_server.app.id
  
  triggers = {
    reset_time = timestamp()
  }
}
```

## Schema

### Required

* `server_id` - (Number, ForceNew) Server ID to change password.

### Optional

* `triggers` - (Map of String) Map of values that, when changed, will trigger password reset.

### Read-Only

* `id` - (String) The server ID.
* `password` - (String, Sensitive) The new root password.
* `last_reset` - (String) Timestamp of the last password reset.

~> **Note:** The new password is generated by VDSina and returned in the `password` attribute.
